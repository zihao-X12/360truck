# 发布准备检查报告（2026-07-30）

## 结论

MySQL 8 目标环境的发布前自动化检查与核心业务回归通过，可以进入业务人员 UAT 和部署参数确认阶段。

PostgreSQL 实机回归按用户要求取消。本次仅保留 PostgreSQL 初始化及增量脚本，不将 PostgreSQL 列为已验证的生产数据库。

## 清理与恢复

- MySQL 初始化演练临时数据库已删除。
- 权限、预警和导入测试车辆已删除。
- PostgreSQL 未完成下载文件已删除。
- Redis 登录验证码配置已恢复为 `true`。
- 前端、后端、MySQL 和 Redis 本地开发服务保持运行。

## 发布前人工确认

1. 使用真实业务台账执行一次 UAT 导入，并抽查车辆、主体和安全设备字段。
2. 确认生产 MySQL、Redis、JWT、上传目录、日志目录和备份配置。
3. 修改 `admin`、`xiping_admin`、`truck_leader` 初始密码。
4. 按实际人员创建账号并删除或停用验收账号。
5. 确认 Nginx `/dev-api` 代理、上传大小、导出超时和 HTTPS 配置。
6. 按 [`truck-platform-acceptance.md`](truck-platform-acceptance.md) 完成人工验收签字。

## 发布限制

- 当前发布结论仅覆盖 MySQL 8。
- PostgreSQL 仍是代码和 SQL 兼容目标，但在独立 PostgreSQL 环境回归前不可宣称生产验证通过。
- 当前预警规则通过数据库配置，尚未提供规则维护页面。
