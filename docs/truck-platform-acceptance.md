# 大货车管理平台验收清单

## 1. 环境与初始化

- [ ] MySQL 8、Redis、后端和前端服务启动正常。
- [ ] 基础 SQL 与对应业务初始化 SQL 按顺序执行成功。
- [ ] 松阳大队及六个中队组织数据正确。
- [ ] 七类业务字典和默认预警规则存在。
- [ ] `admin`、`xiping_admin`、`truck_leader` 可登录且已修改初始密码。

## 2. 主体与车辆

- [ ] 可新增、查询、修改和删除无关联车辆的主体。
- [ ] 有关联车辆的主体禁止删除并返回明确提示。
- [ ] 车辆新增、修改、详情和软删除正常。
- [ ] 车牌号与车牌颜色组合唯一校验正常。
- [ ] VIN 自动转大写且限制为 17 位。
- [ ] 车辆安全设备、照片和归属主体保存正常。
- [ ] 转出或报废车辆不可继续编辑。

## 3. Excel 台账

- [ ] 可下载导入模板。
- [ ] 真实 15 列台账可导入。
- [ ] 扩展模板可导入。
- [ ] 超过 500 行时拒绝导入。
- [ ] 错误行包含工作表、原始行号、原始数据和真实错误信息。
- [ ] 错误文件可在 30 分钟内下载。
- [ ] 车辆和预警可按当前筛选条件导出。

## 4. 看板与预警

- [ ] 首页车辆、主体、来源、监管和预警统计与列表一致。
- [ ] 六个中队统计均展示，点击车辆数可下钻。
- [ ] 两类设备覆盖率计算正确。
- [ ] 缺两项设备生成一级预警。
- [ ] 缺一项设备生成二级预警。
- [ ] 设备齐全时清除重点监管标志。
- [ ] 转出、报废、已删除车辆不参与预警重算。
- [ ] 一级、二级预警卡片可下钻到对应列表。

## 5. 权限

- [ ] 大队管理员可访问全量数据和全部业务操作。
- [ ] 西屏中队管理员只能看到西屏中队主体、车辆和统计。
- [ ] 西屏中队管理员不可录入其他中队数据。
- [ ] 领导账号可查询和导出全量数据。
- [ ] 领导账号看不到新增、修改、删除、导入和预警重算按钮。
- [ ] 领导直接调用写接口时返回无权限。

- [ ] 375px 和桌面视口无异常重叠或横向溢出。
